# Tailor to a job (`/tailor`)

> Overrides `../MASTER.md`. Only deviations and page-specific rules are listed; everything else follows the Master.

- Order follows the task: pick the resume version, then the tabs in use order: Match a job, Create tailored version, Build & check, Content. A one-line hint under the tabs says what the current tab does.

- Creating a version ends with "Build & check it".
